# Changelog

## 0.1.0 — auditable development release

- Added a full-rank named batch design supporting `group = NULL`.
- Made TMMwsp the default and calculate effective library sizes before filtering.
- Added counterfactual reference-batch prediction preserving group and covariates.
- Added deterministic mid-P, upper-CDF, and seeded randomized NB mapping.
- Added diagnostic-only edgeR QL support with separate NB and QL dispersions.
- Added explicit unsupported-gene status and compact model diagnostics.
- Added CLI method controls, tests, methodology, validation, and implementation reports.

No performance superiority or external-validation claim is made.
